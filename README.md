# Download Page — GitHub Pages

Готовая статическая страница с прямым скачиванием файла `panel_export.7z`.

## Структура

```text
.
├── index.html
├── style.css
└── downloads/
    └── panel_export.7z
```

## Публикация

1. Создай репозиторий `USERNAME.github.io`.
2. Загрузи `index.html`, `style.css` и папку `downloads`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`.
6. Открой `https://USERNAME.github.io/`.

Кнопка на странице уже настроена на `downloads/panel_export.7z`.
